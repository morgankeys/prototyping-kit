# Component ports

Written by the `design-system-export` skill when `Docs/Design system/Guidelines/components.md`
lists a component whose Code path exists. The deterministic export reads `manifest.json`
here and packages the ports that pass its checks.

Until that happens, this folder has no manifest and the export ships tokens and guidelines only.

See `Agents/skills/design-system-export/SKILL.md` for the manifest shape and the port rules.
Do not add a component that is not in the inventory.
