# Examples

`react/` holds the React ports from a kit built on Astro and Vue (morgankeysdotcomv3):
`Button.tsx` and `IconButton.tsx` port Vue single-file components, `Tag.tsx` an Astro one.
Use them as a pattern for `Code/design-export/react/`: same element structure, class
names, and `data-*` attributes as the original, with props typed and documented. They are
reference only and are not run.
