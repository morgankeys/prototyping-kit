# Design system

The design system this prototype is built against, and where each kind of source for it
lives. Agents load the same links from
[`Agents/context/design-system.md`](../../Agents/context/design-system.md).

The prototype needs a source of truth for tokens. Figma is the default: export variables
from the library file into [`Figma/Tokens/`](Figma/Tokens/). A team can instead maintain
tokens in this kit or a separate repository and feed both the prototype and Figma, or use
another design tool, as long as the tokens are stored here.

## Figma files

- **Site file** — pages and features to implement: `<Figma link to the site file>`
- **Library file** — core styles; tokens are exported from here: `<Figma link to the library file>`

The library file may or may not define variables. Anything it doesn't define as a
variable belongs in `Supplemental/` or `Guidelines/`.

## In this folder

| Folder | What goes in it |
| --- | --- |
| [`Figma/`](Figma/) | Everything that comes straight out of Figma. [`Tokens/`](Figma/Tokens/) holds the variables exports and their unpacked JSON; [`Assets/`](Figma/Assets/) holds exported mockups, images, icons, and the like. |
| [`Supplemental/`](Supplemental/) | Extended tokens and assets that are not literally Figma variables: sourced from production code, maintained by hand, or anything else. |
| [`Guidelines/`](Guidelines/) | Written patterns and guidelines that tokens don't define, one file per topic (color, typography, layout, components, …). |

Also at this level:

- [`design-in-code architecture.md`](design-in-code%20architecture.md) — how the design
  system is implemented and validated in code.
- `deviations-backlog.md` — generated by `validate`; appears after the first run.

To hand the system to another AI tool (Lovable, Figma Make, …), run `/export-design-md`.
It generates a portable `Export/DESIGN.md` from this folder; see
[`Agents/skills/export-design-md/SKILL.md`](../../Agents/skills/export-design-md/SKILL.md).

After a new Figma export, follow
[`Agents/skills/design-tokens/SKILL.md`](../../Agents/skills/design-tokens/SKILL.md).
