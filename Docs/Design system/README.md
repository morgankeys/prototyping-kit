## Figma files

- **Site file** — pages and features to implement: `<Figma link to the site file>`
- **Library file** — core styles; tokens are exported from here: `<Figma link to the library file>`

The library file may or may not define variables. Anything it doesn't define as a
variable belongs in `Supplemental/` or `Guidelines/`.

## In this folder

| Folder | What goes in it |
| --- | --- |
| [`Figma/`](Figma/) | Everything that comes straight out of Figma. [`Tokens/`](Figma/Tokens/) holds the variables exports and their unpacked JSON; [`Assets/`](Figma/Assets/) holds exported mockups, images, icons, and the like. |
| [`Supplemental/`](Supplemental/) | Extended tokens and assets that are not literally Figma variables: sourced from production code, maintained by hand, or anything else. |
| [`Guidelines/`](Guidelines/) | Written context, as docs or Markdown, capturing patterns and guidelines that tokens don't define. |

Also at this level:

- [`design-in-code architecture.md`](design-in-code%20architecture.md) — how the design
  system is implemented and validated in code.
- `deviations-backlog.md` — generated by `validate`; appears after the first run.
