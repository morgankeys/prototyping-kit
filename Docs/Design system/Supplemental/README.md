# Supplemental

Extended tokens and assets outside the main token export. That export usually comes from
Figma variables and lives in [`../Figma/Tokens/`](../Figma/Tokens/). What goes here may be
sourced from production code, maintained by hand, or come from anywhere else.

Examples: breakpoints, z-index scales, motion durations and easings, shadows defined only in
code, brand assets from a marketing repo.

For each file, say where it came from and how to refresh it, either in the file's header or
in a list below, so the next person knows whether it is copied or authored here.
