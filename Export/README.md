This folder is a place to export built versions of the prototype for manual transfer to a server or platform.

It also holds `DESIGN.md`, a portable summary of the design system for other AI tools, once `/export-design-md` has been run, and `design-system/` once `npm run ds-export` has been run. Both are generated: edit `Docs/Design system/` and re-export instead of editing them. `design-system/` is gitignored.
